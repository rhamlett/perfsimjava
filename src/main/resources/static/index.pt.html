🎮 Controles de Simulação

🔥 CPU Estresse i️

Gera threads de trabalho executando operações criptográficas intensivas para estressar CPU núcleos.

📊 Pressão de Memória i️

Aloca blocos de buffer preenchidos com dados aleatórios. Pilha de múltiplas alocações - imita vazamento gradual de memória.

🧵 Falta de Poças de Fios ⚠️

Bloqueia os fios servlet para simular o esgotamento do pool de fios. O servidor fica sem resposta a novas solicitações.

⏱️ Nota sobre a Duração: Cada solicitação de bloqueio é executada pelo tempo especificado. Se threads > tamanho do pool (~200), solicitações excedentes entram em fila e rodam em ondas. Tempo total ≈ duration × ⌈threads/200⌉.

🔌 Pool de Conexão i️

Simula o esgotamento do pool de conexão JDBC. Consultas simultâneas excedem a capacidade do pool, causando timeouts – um problema comum de produção em Java.

🔍 Os dumps de threads mostram threads ESPERANDO no Semaphore - idêntico ao esgotamento do pool HikariCP/C3P0.

❌ Pedidos Fracassados i️

Gera HTTP 500 erros ao acionar requisições com probabilidade de erro de 100%. Erros aparecem em AppLens e Application Insights.

📊 Cada requisição realiza trabalho visível antes de falhar, aparecendo no Monitor de Latência de Requisição.

💥 Crash de Aplicação ⚠️

Encerra o processo da JVM. Azure reinicialização automática - observe a recuperação no Registro de Eventos.
