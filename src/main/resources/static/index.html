🎮 Simulation Controls

🔥 CPU Stress ℹ️

Spawns worker threads running intensive cryptographic operations to stress CPU cores.

📊 Memory Pressure ℹ️

Allocates Buffer blocks filled with random data. Multiple allocations stack - mimics gradual memory leak.

🧵 Thread Pool Starvation ⚠️

Blocks servlet threads to simulate thread pool exhaustion. Server becomes unresponsive to new requests.

⏱️ Duration Note: Each blocking request runs for the specified duration. If threads > pool size (~200), excess requests queue and run in waves. Total time ≈ duration × ⌈threads/200⌉.

🔌 Connection Pool ℹ️

Simulates JDBC connection pool exhaustion. Concurrent queries exceed pool capacity, causing timeouts - a common Java production issue.

🔍 Thread dumps will show threads WAITING on Semaphore - identical to HikariCP/C3P0 pool exhaustion.

💥 Application Crash ⚠️

Terminates the JVM process. Azure auto-restarts - observe the recovery in Event Log.

⚠️ This will TERMINATE the app!
